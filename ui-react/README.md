# ui-react

A modern React UI application built with Vite.

## Features

- **Vite** - Lightning-fast build tool
- **React 18** - Modern UI framework
- **ES Modules** - Modern JavaScript modules

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```
